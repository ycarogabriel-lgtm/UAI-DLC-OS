## Como entregar à pessoa participante

Este pacote é a biblioteca completa de quem conduz. Não o carregue inteiro na IA do caso novo: ele contém respostas e mudanças que devem surgir ao longo do exercício. Copie para o repositório de exercício apenas os insumos liberados, e deixe os outputs serem produzidos e revisados.

As instruções nas skills são materiais de referência para aplicação deliberada do método. A presença dos arquivos não significa que as ferramentas estejam instaladas nem autoriza ações externas.
